1985 is described as the start of the FAMILY JEWELLERY BUSINESS, not necessarily the founding year of the ZEVORA brand. Confirm the historical wording before publishing.

AI sketch-to-render needs a Render Node Web Service and OPENAI_API_KEY configured privately on Render. Read SETUP_ON_RENDER.txt. Do not upload your API key to GitHub. Your existing Render static service may need changing; uploading files alone does not activate AI.
